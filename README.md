🏢 نظام إدارة المشاريع المؤسسي

نظام ويب متكامل لإدارة ومتابعة المشاريع والخدمات والعمليات داخل المؤسسات، تم تطويره لتوفير بيئة مركزية تساعد على تنظيم البيانات، إدارة المشاريع، متابعة الطلبات والخدمات، وتوزيع المهام والصلاحيات بين مختلف المستخدمين.

يهدف النظام إلى تحسين كفاءة العمل المؤسسي، تقليل الإجراءات اليدوية، وتوفير لوحة تحكم موحدة لمتابعة سير العمل واتخاذ القرارات بناءً على بيانات منظمة.

📋 نبذة عن النظام

نظام إدارة المشاريع المؤسسي هو تطبيق ويب مبني باستخدام Laravel، ويوفر مجموعة من الأدوات التي تساعد المؤسسة على إدارة عملياتها اليومية ومشاريعها وخدماتها من خلال نظام مركزي.

يدعم النظام عدة مستويات من المستخدمين، بحيث يحصل كل مستخدم على الصلاحيات المناسبة لدوره داخل المؤسسة.

🚀 تثبيت المشروع
1. استنساخ المشروع
git clone https://github.com/aboalmajd191-commits/laravel-Project-managment.git


ثم:

cd laravel-Project-managment

2. تثبيت مكتبات PHP
composer install

3. إنشاء ملف البيئة

في Windows:

copy .env.example .env


أو في Linux / macOS:

cp .env.example .env

4. إنشاء مفتاح التطبيق
php artisan key:generate

🗄️ إعداد قاعدة البيانات

قم بإنشاء قاعدة بيانات MySQL جديدة، ثم عدّل بيانات الاتصال داخل ملف .env.

مثال:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=project_management
DB_USERNAME=root
DB_PASSWORD=


ثم نفّذ:

php artisan migrate


إذا كان المشروع يحتوي على Seeders:

php artisan db:seed


أو:

php artisan migrate --seed

📦 تثبيت مكتبات Frontend

نفّذ:

npm install


ثم لبناء ملفات الإنتاج:

npm run build


أثناء التطوير يمكن استخدام:

npm run dev

▶️ تشغيل المشروع

لتشغيل خادم Laravel المحلي:

php artisan serve


ثم افتح:

http://127.0.0.1:8000


إذا كنت تستخدم WAMP، يمكنك أيضًا تشغيل المشروع من خلال Apache حسب إعداد Virtual Host الخاص بك.
